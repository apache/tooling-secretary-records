Admins (the Tooling team) look after the instance. They do not read the queue.

## Server status

*Server status*, in the header, says which database the instance runs on, which
migration it is at, whether outgoing mail is configured, and who holds each
role. From there, *Browse the database* lists the tables an admin may see, and only
their columns that hold no personal data. ICLA submissions are not among them.
