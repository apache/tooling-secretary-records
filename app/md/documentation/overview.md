Secretary Records processes the paperwork that arrives at `secretary@apache.org`:
ICLAs, CCLAs, software grants, membership applications, emeritus requests and
withdrawal requests. For each document it gets from "email received" to "filed
in SVN, indexes updated, directory updated, submitter answered".

This page grows with the tool. Each section below describes one role's work;
the ones marked *yours* are the roles you hold.

## Who can see what

The queue holds personal data, so only the Secretary, the Assistant Secretary
and the secretarial team can see it. ASF members at large have no access.
